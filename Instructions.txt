Run Kubesparay

docker run --rm -it --mount type=bind,source="$(pwd)"/clusters/dev-ap-south-1,dst=/inventory \
  --mount type=bind,source="${HOME}"/.ssh/mumbai,dst=/root/.ssh/id_rsa \
  quay.io/kubespray/kubespray:v2.31.0 bash
# Inside the container you may now run the kubespray playbooks:
ansible-playbook -i /inventory/inventory.ini --private-key /root/.ssh/id_rsa cluster.yml

## Configure kubectl in local
* download the file /etc/kuberneties/admin.conf to local 
* change the api ip to 127.0.0.1:6443
* create a ssh tunnel to the server directing local port 6443 to k8 api-server(10.30.0.119:6443)
ssh -i ~/.ssh/mumbai -f -N -L 6443:10.30.0.119:6443   -o ServerAliveInterval=60   -o ServerAliveCountMax=3   ubuntu@65.0.133.87

ssh -i ~/.ssh/singapore -f -N -L 7443:10.31.0.198:6443   -o ServerAliveInterval=60   -o ServerAliveCountMax=3   ubuntu@13.250.51.125

ssh -i ~/.ssh/jumphost -f -N -L 7443:15.204.111.69:6443   -o ServerAliveInterval=60   -o ServerAliveCountMax=3   sagara@134.199.134.29


# Notes
1. Make sure the include in clusters/dev-ap-south-1/group_vars/all/all.yml
ansible_become: true
enable root access
2. Inventory IP assignemnt - Kubespray binds kubelet, kube-proxy, and etcd to the ip address — it must be a local NIC address so services can actually bind to it
So make sure assign the IPs in the inventory accordingly. 
Specially in cloud public ip is NAT'd addres so use the NIC bing address so it properly bind
3. Cilium - cgroup permision issues. Not allowed to create additiona cgroup use the latest exisitng cgroupv2 in clusters/dev-ap-south-1/group_vars/k8s_cluster/k8s-net-cilium.yml
cilium_cgroup_host_root: "/sys/fs/cgroup"
cilium_cgroup_auto_mount: false
- /opt/cni/bin ownership is fixed automatically by playbooks/cluster.yml (re-owns to root:root after kubespray creates it with kube/UID-999).
